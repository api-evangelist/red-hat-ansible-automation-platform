# Red Hat Ansible Automation Platform (red-hat-ansible-automation-platform)
Red Hat Ansible Automation Platform is an enterprise automation solution that provides a framework for building and operating IT automation at scale. It includes the Automation Controller, Automation Hub, Event-Driven Ansible, and Ansible Lightspeed with IBM watsonx Code Assistant.

## APIs

### Red Hat Ansible Automation Controller API
Enterprise REST API for centralized automation management with RBAC and audit logging.

### Red Hat Ansible Private Automation Hub API
REST API for managing private Ansible content collections.

### Red Hat Event-Driven Ansible Controller API
REST API for event sources, rulebook activations, and automated response workflows.

### Red Hat Automation Services Catalog API
REST API for self-service automation ordering with governance controls.
